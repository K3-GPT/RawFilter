## 📚 功能总览

### 🗑️ 去除废片

- **回收站功能**：将被判定为废片的文件（例如，仅有JPG而无对应RAW的文件）移动到独立的“回收站”文件夹，避免直接删除造成数据丢失。
- **分类功能**：
    - **`完整`文件夹**：存放同时拥有RAW和JPG格式的文件对。
    - **`单个`文件夹**：存放只有单一格式（RAW或JPG）的文件，供用户复审。

**逻辑**：
1.  遍历指定目录下的所有文件。
2.  基于文件名（不含扩展名）对文件进行归类。
3.  若一个文件名同时对应RAW和JPG两种格式的文件，则判定为“完整”文件，移动到“完整”文件夹。
4.  若一个文件名仅对应单一格式（JPG或RAW），则判定为“单个”文件，移动到“单个”文件夹。

### 🎨 筛选精修

- **兼容性**：允许目录中存在除RAW和JPG格式外的其他文件，程序仅处理目标格式。
- **多RAW格式支持**：能够正确处理多种RAW格式文件（如.CR3, .NEF, .ARW等）与JPG的匹配。
- **交互优化**：增加弹窗，让用户选择是筛选并复制RAW文件还是JPG文件到目标文件夹。
- **界面优化**：改进按钮布局和窗口弹出逻辑，提升UI/UX。

## 🔧 详细功能描述

### 1️⃣ 智能文件处理引擎 (`FileHandler`)

- **目的**：提供全面的文件操作能力，支持复杂的文件匹配和处理逻辑。
- **核心方法**：
  - `move_to_recycle_bin()`: 智能移动疑似废片到回收站，确保数据安全
  - `categorize_files()`: 自动分类文件为"完整"和"单个"文件夹，支持多种RAW格式
  - `remove_waste_files()`: 精准识别并移除废片文件，减少存储占用
  - `get_file_pairs()`: 高效获取文件对信息，支持格式优先级排序
  - `copy_files_by_format()`: 按用户选择格式复制文件，支持进度回调

### 2️⃣ 智能文件分类系统 (`Categorize Files`)

- **目的**：帮助用户清晰管理不同状态的图片文件。
- **分类逻辑**：
  - **`完整`文件夹**：存储同时拥有RAW和JPG格式的完整文件对
    - 支持20+种RAW格式：.CR3, .CR2, .ARW, .NEF, .NRW, .RW2, .RAW, .DNG, .ORF, .RAF, .SRW, .PEF, .IQ, .3FR等
    - 基于文件名（不含扩展名）智能匹配JPG和RAW文件对
    - 自动处理大小写敏感的扩展名匹配问题
  - **`单个`文件夹**：存放无法匹配成对的文件
    - 主要是单独的JPG文件（可能表示RAW文件丢失）
    - 供用户手动检查是否需要补充对应的RAW文件

### 3️⃣ 筛选精修功能 (`Filter Files`)

- **目的**：提供灵活的文件筛选和复制能力。
- **智能匹配**：支持多种RAW格式与JPG文件的精确配对
- **格式选择**：提供用户友好的下拉选择界面，按使用频率排序格式选项
- **目标定制**：用户可自由选择源文件夹和目标文件夹
- **进度跟踪**：实时显示处理进度，包括文件扫描、配对、复制等各阶段
- **错误处理**：完善的异常捕获和用户友好的错误提示机制

### 4️⃣ 用户友好界面 (`RawFilterGUI`)

- **设计原则**：简洁直观，操作流畅
- **界面布局**：
  - 格式选择下拉框：根据使用频率自动排序格式选项（.CR3优先显示）
  - 进度条显示：实时显示操作进度，包括百分比和详细状态信息
  - 居中按钮设计：精心计算的按钮布局，确保视觉平衡
- **交互体验**：
  - 模态对话框：防止误操作的阻塞式弹窗
  - 实时反馈：每个操作步骤都有对应的进度更新
  - 状态提示：清晰的操作完成和错误提示消息

### 5️⃣ 智能日志系统 (`JSON Logging`)

- **结构化日志**：采用JSON格式记录操作详情，便于数据分析和程序集成
- **日志内容**：
  - 时间戳和任务ID：确保每次操作的唯一标识
  - 详细统计：文件移动数量、错误信息、处理状态等
  - 操作路径：记录完整的文件操作路径
- **存储策略**：按日期独立保存JSON日志文件（logs/operation_log_YYYYMMDD.json）
- **数据安全**：日志文件包含完整的操作审计信息，支持操作回溯

### 6️⃣ 模块化架构设计

- **`file_handler.py`**：核心文件处理逻辑
  - 统一的FileHandler类管理所有文件操作
  - 进度回调机制支持实时UI更新
  - 异常处理和错误统计功能
  
- **`gui.py`**：图形用户界面
  - RawFilterGUI类封装所有用户交互
  - 统一的进度更新和日志记录接口
  - 用户友好的错误提示和操作引导

- **`constants.py`**：配置管理
  - 格式常量：支持20+种RAW和JPG格式
  - 界面常量：窗口尺寸、按钮文本等UI配置
  - 进度配置：进度条显示样式和字符定义

### 7️⃣ 性能优化特性

- **内存优化**：使用生成器和迭代器处理大文件目录
- **I/O优化**：批量文件操作减少磁盘访问次数
- **用户体验**：非阻塞式操作，保持界面响应性
- **错误恢复**：完善的异常处理确保程序稳定性

## 💡 使用场景
